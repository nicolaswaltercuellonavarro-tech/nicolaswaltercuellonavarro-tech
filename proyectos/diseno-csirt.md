# Diseño de CSIRT corporativo — Tecnológica Andina

**Tipo:** propuesta académica grupal para un caso de estudio.

## Objetivo

Definir roles, servicios y coordinación de un equipo de respuesta a incidentes de ciberseguridad.

## Diseño documentado

| Rol | Responsabilidad principal |
| --- | --- |
| Dirección del CSIRT | Coordinación, decisiones críticas y asignación de recursos |
| Analista | Monitoreo, análisis inicial, clasificación y priorización |
| Especialista técnico | Contención, erradicación y recuperación |
| Asesoría jurídica | Evaluación de obligaciones y preservación de evidencia |
| Comunicaciones | Mensajes internos y externos coordinados con la dirección |

El ejercicio contempla gestión de incidentes, monitoreo, análisis de amenazas, recuperación y concientización. El flujo propuesto conecta detección, escalamiento técnico, evaluación jurídica, comunicación y coordinación general.

## Alcance

Propuesta conceptual de clase, sin despliegue operativo ni métricas de un CSIRT real. Este resumen omite las interpretaciones legales del original: no constituye asesoría jurídica ni una validación de plazos regulatorios.
